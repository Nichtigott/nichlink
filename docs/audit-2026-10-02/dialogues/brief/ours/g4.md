# g4 — 这棵树里有哪些臂是没有任何执行能进入的（只读）
**① 症状（问题）** 题面：哪些臂没有任何执行能进入；给出每条判据；并说清哪些判不了、为什么。树只读，未改动。
`check {face:default}` → `verdict passed (cargo exit 0)`（7 个测试二进制全绿），所以答案不在红里，在静态事实上。
**② 判得了的（2 条，判据逐条不同）** 1. **`crates/core/src/bands.rs:36-41` 的 `if false` 块**（`fn band_word`，定义 :35-56）。
   判据：常量假守卫——`false` 是字面量，没有输入、没有运行期状态、没有展开能进入该块。
2. **`crates/core/src/bands.rs:54` 的 `Band::Frozen` 臂**（`match band` 在 :49-55）。
   判据：本树没有任何地方构造 `Band::Frozen`（本树唯一的 `Band` 构造是 `:61` 的 `Band::Small`），
   而 `enum Band`（:24-31）是**私有**的 ⇒ 本树之外的构造器也拼不出该变体 ⇒ 按构造不可达。
**③ 判不了的（2 条 + 每条的为什么）** 3. **`crates/core/src/bands.rs:42-48` 的 `amount > limit` 臂**。**判不了**：它是否被走到是**数据相关**事实
   （`band_word` 的参数），静态读取不许下结论。现有测试确实一次没走（`bands_tests.rs:14` 只传
   `default_band(), 1, 1000`，`1 > 1000` 为假），但「本套件没走」≠「没有任何执行能进入」——
   换一组参数（如 `band_word(Band::Small, 2000, 1000)`）就能进入 ⇒ 只能说「未被执行过」，不能说「不可达」。
4. **`crates/core/src/bands.rs:92` 的 `State::Dormant` 臂**（`fn state_word`，:88-94）。**判不了**：
   本树没有构造它，但 `pub enum State`（:68-78）是**公开表面**——外包使用者可以构造它 ⇒
   把它列为不可达等于对「该 crate 的每一个使用方」下结论，而不是对这棵树。
**④ 证据** `check {face:default, census:true}` → `branch-level: 2 constructively unreachable arm(s) in this tree
