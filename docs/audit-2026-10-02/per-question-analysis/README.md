## 五、你要产出什么（每题一节，中文为主，代码标识符/路径保留英文）

对**分到你的每一道题**，按这个骨架写（引用必须**逐字**，带出处；不许转述成笼统结论）：

```
### `<id>` · <题面一句>
**我们臂的路径**：N 次仪器调用，序列 = `工具 {参数}` → `工具 {参数}` → …
  - 每次调用**拿到了什么**（引工具返回里的关键行，逐字）
  - **决定性的一步**：哪一次调用给了"可以下结论"的信息；agent 当时的推理原文怎么说
**codegraph 的路径**：同上
**两侧差异与归因**：为什么一侧多走/少走；差异是**工具的哪一行信息**造成的（不是"它更聪明"这种话）
**代价**（引上表）：仪器 N vs M · 输出 x vs y · 推理 a vs b · 上下文 c vs d
**质量**（引第四节）：我们 <判定+依据> · 它 <判定+依据>
**引导含义**：要让 agent 更少浪费/更对，这一题说明工具的**哪一处**（答案里的哪一行、拒绝文案、流程表、schema）该改；
  这一条要**具体到可实施**（例如"`check` 的 `why` 行应带上 X"），并注明依据是对话里的哪一句原文。
```

## 六、纪律（违反会让这份分析作废）

1. **逐字引用**：所有关键判断都要能指到原文的一行（工具返回 / 推理 / 答案）。找不到原文就写"无法判定"。
2. **不重做判定**：质量判定与代价数字用上面已核定的；你只做**对话层**的分析。
3. **不采信自报**：臂在答案末行自报的"调用 N 次"可能与日志不符——一律以**逐题日志条数**为准。
4. **只读**：不要修改任何题树、日志、答案、别人的产物文件；你只写自己被指派的那一个文件。
5. **不确定要标出来**：证据不足、口径含糊、装置可疑，都要在文末"没能判定"一节里写清。
6. **别写"它更聪明/更强"这类话**：差异必须落到可指出的信息差或流程差上。
