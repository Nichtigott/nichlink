# 威胁模型

[English](threat-model.md) | 简体中文

## 资产

- 宿主注册树及其父链、合同不变量；
- 插件字节、签名、校验和、lock 记录和撤销信息；
- 宿主进程及传给插件的数据。

## 信任边界

core 声明只是元数据，不执行插件代码。Studio 和 debug collector 是开发工具。Wasm 与进程适配器是独立执行边界；进程适配器每次调用使用新的子进程。

## 控制措施

- release 使用经过检查的 `StaticPlan`，不保留 inventory linker section；
- 外部注册面在发布前校验来源、框架、版本、父节点和合同闭合；
- 官方插件需要匹配信任策略和签名，社区/本地插件至少需要已验证 checksum；
- Wasm 限制线性内存、fuel、输入和输出大小；
- 进程调用使用 framed I/O、大小限制和硬超时，超时子进程会被终止；
- 热替换在同一 generation 发布代码和 Registry，健康检查或 graft 失败会保留旧版本；
- 撤销和流程版本不匹配会在激活前拒绝候选。

## 剩余风险

普通库无法证明任意 Rust 动态分派、函数指针、FFI 和优化后局部变量的完整事实。MIR 候选和未观测值必须带证据标记并保守回退。Wasm 内存限制也不等于逻辑安全，应用仍需选择合适的合同和能力范围。
