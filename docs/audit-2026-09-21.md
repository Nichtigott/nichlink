## Batch 1 / 批 1

- **B1.1 CRITICAL 切分器不是 Rust 感知的** `[新(b) / 既有(a)]` —
  `core/src/registry_core/syntax/syntax.rs:448` `split_face_fields`, `:484`
  `starts_face_field`. (a) `preset: crate::P<u8, u16>` / `Flow::<u8,u16>::new()`
  → builder `parse_face` panics (`build_method/src/validation.rs:146`) while the
  compiler accepts it (strict arm `run_method/src/macros/macros.rs:470`).
  (b) `flow: |a: u32| a` → **silent** misread: `flow = "|"`, phantom field `a`.
  Fix: track angle depth (`<`/`>` are punctuation, `>>` closes two), and only
  treat `name:` as a field start when the name is in `FACE_FIELD_ORDER`.
- **B1.2 MAJOR IDE 镜像不是合法 Rust，且文档声明为假** `[新]` —
  `run_method/src/macros/macros.rs:763-792` (fields typed `()`), `:818-824`;
  emitted at `build_method/src/renderer.rs:137`. `RUSTFLAGS='--cfg rust_analyzer'
  cargo check -p nichlink-example-control-button` → 66 errors (54×E0308,
  6 bare-struct-body, 3×E0560 `source`, 3×E0425). `source` is missing from
  `FACE_FIELD_ORDER` (`core/src/registry_core/declaration/declaration.rs:1665`).
  Fix: add `source`, and state the truth (the mirror is deliberately never
  type-correct; it exists only for field-name completion).
- **B1.3 MAJOR 前端是最后一条 arm，看到的是阶梯注入后的输入** `[新]` —
  `run_method/src/macros/macros.rs:451-465` injects `preset`/`parts` before the
  front end, so `kind, handle, preset, parts` reports "`preset` is given twice";
  `preset` without `parts` plus `handle` is unrepresentable (`:470` both
  mandatory, `:546` neither, `:608` no handle) and reports the misleading
  "already in the accepted order" guard (`macro/src/lib.rs:128`). Also:
  duplicate `collector` silently last-wins (`macro/src/lib.rs:73-76`) while the
  builder errors; `external_object!` has no fallback (`:848-862`).
  Fix: make the front end the first stop for author input, dedupe `collector`,
  route `external_object!` through it.
- **B1.4 MAJOR 尾逗号改变最小面的注册槽** `[既有 / 恶化]` —
  `kind: X` matches only `run_method/src/macros/macros.rs:685` → `registry_name
  = stringify!(kind)` (`:704`); `kind: X,` matches `:608` → `last_path_segment(
  module_path!())` (`:661`, the file stem). Logical path flips on a comma. The
  front end always emits a trailing comma, so it normalises `kind: X;` into the
  second form. Fix: make both arms default to the same registry name.
- **B1.5 CRITICAL 流合同门被绕过** `[既有]` —
  `core/src/registry_core/declaration/declaration.rs:1396-1403` (and
  `:1482-1489`) guard only `input != Unknown`; `flow_semantic` (`:1492-1504`)
  knows 4 labels, so two unrecognized *outputs* compare equal and a
  type-incompatible replacement is accepted (`graft_ops.rs:149-152`,
  `plugin/slot/slot.rs:107-116`). Fix: `Unknown` must not be compatible.
- **B1.6 CRITICAL `CallTrace` 作用域深度下溢** `[既有]` —
  `run_method/src/runtime/trace/trace.rs:142` `clear()` zeroes
  `error_scope_depth`; `set_mode()` calls it (`:120-123`); the matching `-= 1`
  at `:205` underflows. Debug panics; release wraps to `usize::MAX` and
  ErrorsOnly rollback silently degrades to Full.

## Known clean / 审计判定干净的区域

Identity hashing (standard vectors, `0x00` separator inside the digest, `\`/`/`
folding, namespace+path compressed to 128 bits, exact display/parse round-trip,
separate root domains); transaction construction (pre-mutation rejection of
namespace mismatch, duplicate `NodeId`, duplicate `stable_name`, cycles, missing
parents; failures leave the receiver untouched; page COW prevents aliasing);
graft staging (validate-before-mutate, duplicate cuts by resolved id, inclusive
name-ordered ranges, correct rebasing, external tree unmutated); admission
(component-boundary matching, no substring bypass; exact capability and provider
kind over the ancestor chain with cycle guards); release plan
(`assert_static_registration` mirrors rule and contract exactly; both
`IDENTITY_SCHEMA` constants agree); plugin trust chain (exact channel/framework/
mode arms, Official⇒Signature, full 64-hex digests, opaque immutable verified
artifact); kernel purity (no fs/env/process in `core/`); the incremental build
cache cannot go stale (unit key = absolute path + contents, ids revalidated
against the current namespace); `<dir>/<dir>.rs` layout violations panic loudly.
