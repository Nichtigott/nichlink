# 场景判定的夹具：35 条（七形状 × 四措辞 + 一判别对）

用途：**T-21 那一轮大测试的输入**，以及**防漂移**（本文件的七个形状名与流程表里那七行必须一致——由
`client_tests.rs` 的一条钉子读本文件断言，两边都查）。

**可判定的与不可判定的，先分清**：
- **可判定（Rust 已测）**：流程表里七行齐全、每行有停止条件、每个停止条件都点名一个**能产出该事实的调用**
  （T-09/T-11 的钉子），以及本文件的形状集合与流程表一致（本文件的钉子）。
- **只能在大测试里量（T-21）**：**模型是否把这些措辞真的落到了同一个形状**。那是模型行为，**不许在单元测试里
  伪造一个绿**——本文件是它的输入，不是它的证明。

**结构信号**三栏：`点名`（几个对象）/ `方向`（查看·新增·加深·迁移）/ `树`（空·已有）。判据是这三栏，**不是措辞**。

## 这 35 条怎么用（T-21）

1. 每一轮把一条说法**原样**交给被测臂（不含本文件的任何结构标注）；
2. 记下它选的形状、第一次调用、以及它是否在**停止条件**处收手；
3. 判据：**同一形状的四条放一起看一致率**，判别对单列（它们唯一的用途就是看**措辞有没有压过结构信号**）；
4. 本文件**不进题面**：臂只看得到说法，看不到期望值。
