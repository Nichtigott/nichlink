This is the hand-off list for the next session. Every item below was found by running
NichLink on real projects, not by reading code. The memory entry `0mv0esed` carries the
same list with the raw evidence; this file is the repository copy so no chat history is
needed.

**The goal of this batch is to close the 0.2.x line: every item below either fixed and
verified, or explicitly parked with a reason. `move` is part of this batch.** The next
phase (multi-language / cross-platform / distributed compilation) starts only after this
line is closed.

**Definition of closed** — all four hold: (1) every A/B/C item below is either fixed or
parked with a written reason; (2) `cargo fmt --check`, both clippy faces, the workspace
test run, the ten-face runner, the partition rehearsal and the daily-behaviour matrix are
green; (3) each fix is reproduced by hand in a real project (not only in a fixture);
(4) `move` is implemented with its record, and its scenarios are exercised in the same
hand-built project.

**Discipline that this list was produced under** — test first, fix second; every claim is
a command's raw output; "reporting the problem" and "fixing the problem" are two
different delivery levels, and only the second counts.

## A. Real defects, in the order I recommend fixing them

| # | What is wrong | Evidence | Suggested fix |
| --- | --- | --- | --- |
| 1 | In the **release shape** the generated crates and the facade carry **no cuts of their own** (release: host 2, ghosts 0, facade 0; development: every package carries everything). A published crate therefore never applies its own graft. | reproduced twice: `target/real-usage/consumer`, `/tmp/nichlink-lab/dash` | each package carries only the cuts for the faces it compiles, in both shapes; assert attribution, not just rc=0 |
| 2 | The **host emits cuts for faces it does not compile** (both shapes). | same two rigs | the ownership gate must cover both emission paths |
| 3 | An **external plan is only matched against string cuts**, so it and `promote` are mutually exclusive: `promote` demands a Rust path, the record demands a string. | A/B experiment in the lab | let the checker resolve a typed cut's expression to its node/logical path — the renderer already has that mapping |
| 4 | `crates --declare --write` **writes a declaration that is not valid Rust** (rc=0, and `check` stays green on the broken file). | `target/real-usage` and the repository's own example | maintainer parked it for the rename batch; the reader half ("refuse unbalanced brackets") can be fixed now |
| 5 | Host on a **path** dependency plus a third party on git/registry ⇒ **two toolchain copies** ⇒ `E0308` inside a **generated** file. | the lab | refuse by name and offer "both sides from the registry" |
| 6 | When the host manifest **is its own workspace**, a split writes packages that **belong to no workspace** ("no member list"), so the project's own `cargo build` never touches them. | the lab | list them as members, or say where to add them |
| 7 | A plan with cuts **silently prunes** every subtree that is not a declared slot — even one the declaration claims. Only `explain --overlay` says so. | the lab | `check`/build says "N faces are outside your slots", with the paste-ready self-graft line |
| 8 | A **`full`** cut still lists the children in the overlay, against the pin `full_discards_base_children_and_non_full_keeps_them`. | the lab | find out whether the preview does not model `full`, or the behaviour regressed |
| 9 | The program's own **face count prints 0** while `explain` reports 7 faces. | the lab | find what `builtin_static_plan()` counts |
| 10 | An external plan and the static plan that **disagree on the graft name** are accepted silently. | the lab | say which one wins |
| 11 | Two **identical string cuts** for one slot make the build fail with a reason that contradicts the file. | the lab | check whether it shares a root cause with #3 |
| 12 | The **nesting guard counts doc-comment tokens**, so a mainstream crate is refused: `tokio/src/fs/mod.rs` has 213 consecutive `//!` lines ≈1065 tokens, above `CHAIN_LIMIT = 1024`. | `/tmp/real-projects/tokio` | do not count `#[doc]` tokens in the chain counter; raise the limit toward the measured-safe margin; add a real-project case to `nesting_budget` |
| 13 | The bridge's `explain` **never says which implementation replaced a slot** (the CLI's `explain --overlay` does), and a host has **no public way to reach its registry at runtime**. | the lab | add that half-sentence to the bridge; or give the host a lookup entry |
| 14 | Renaming a face file is refused with a **layout** reason, never with the **identity** reason. | daily-behaviour matrix | add "renaming changes the identity, old records stop resolving" and point at the move record |
